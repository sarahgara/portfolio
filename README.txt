PORTFOLIO STYLISTE-MODELISTE
=============================

Fichiers :
- index.html : structure et contenu du site
- style.css  : design responsive
- script.js  : menu mobile et année automatique

PERSONNALISATION
1. Ouvrez index.html.
2. Remplacez « ATELIER ÉLISE », « Prénom Nom », les textes, l'adresse e-mail,
   Instagram et la localisation par vos informations.
3. Remplacez les URL des images dans index.html par vos propres photos.
   Conseil : créez un dossier « images » dans le projet et utilisez par exemple
   src="images/ma-creation.jpg".

PUBLIER AVEC GITHUB PAGES
1. Connectez-vous à GitHub et créez un nouveau dépôt (repository), par exemple
   portfolio-styliste.
2. Téléversez index.html, style.css et script.js à la racine du dépôt.
3. Ouvrez Settings > Pages.
4. Dans « Build and deployment », choisissez « Deploy from a branch ».
5. Choisissez la branche main et le dossier / (root), puis cliquez sur Save.
6. Après quelques instants, GitHub affichera l'adresse publique du portfolio
   dans Settings > Pages.

Le site est adapté aux téléphones, tablettes et ordinateurs.
